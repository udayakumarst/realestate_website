# 🏗️ Real Estate & Construction Website

A modern, high-conversion showcase website built with **Next.js 16 (Turbopack)** and **Tailwind CSS 4**, featuring a warm **Wood, Cream, Sand, and Brick** 3D architectural aesthetic.

---

## ⚡ Quick Start

```bash
# Install dependencies
npm install

# Run local development server
npm run dev
# Website is live at: http://localhost:3456 (or http://localhost:3000)

# Build for production
npm run build
```

## 🚀 Deployment to Live Internet (Vercel)

When you're ready to share your site publicly:
1. Initialize git and commit your files:
   ```bash
   git add .
   git commit -m "Update real estate site with 3D theme"
   ```
2. Push to your GitHub account repository.
3. Import the repository into [Vercel](https://vercel.com) (free tier works instantly).
4. Connect your custom domain (e.g. `yourcompanyname.com`).
